Telemetrix

Open Source (Apache 2.0) · Built in Rust · Windows 11 and Linux

Your system, live, in about 8 MB.

Telemetrix is a very light terminal screensaver and live system dashboard. It shows your CPU, memory, disks, GPU and temperatures, plus cards for exchange rates, crypto prices, weather and more. It uses almost no CPU on the static theme.

Download for Windows Download for Linux View on GitHub →

Unpack the zip and run telemetrix.exe from Windows Terminal. The file is not signed yet, so Windows warns once: click "More info", then "Run anyway". Or build it with Rust 1.95 or newer: cargo install --git https://github.com/OliverD25/telemetrix

What it shows

Every number you glance at, in one terminal

The core cards read your own computer. Plugin cards bring in outside data. The plugins need no account and no key. If a service does not answer, the card keeps its last values and marks them stale.

  • System

    CPU, memory, swap, GPUs, disks, and CPU and GPU temperature where your computer reports it.

  • Markets

    Crypto prices from Binance. Currency rates from Monobank, PrivatBank and NBU. Graphs for 7 days, 30 days and 1 year.

  • Weather

    Now and two days ahead, from Open-Meteo (data under CC BY 4.0).

  • Network

    Latency to 1.1.1.1, measured with a TCP connect. A speed test every 30 minutes, or when you press g.

  • Clock and uptime

    The time, and how long the computer has been running.

  • Your own plugins

    Write a small Lua file and get a card for it. Each plugin has its own memory limit.

Ten themes

Ten themes, from quiet to cinematic

  • matrixDigital rain behind the cards. The default.
  • minimalistGrey cards, with colour only where a value crosses its threshold.
  • tokyo-nightThe Tokyo Night colours: dark slate with quiet blues and purples.
  • crt-amberAn old amber monitor, with heavy frames and scanlines.
  • cyberpunkA neon HUD: magenta titles, cyan frames, yellow values.
  • nasaA mission control console with NOMINAL, CAUTION and WARNING rows. Static.
  • pip-boyA green wrist-computer screen with bracketed tabs and gauges. Static.
  • synthwaveAn 80s neon sunset with a striped sun and a moving wireframe floor.
  • kernel-logA Linux boot log: every change of a value adds a line, and the view scrolls.
  • ascii-dashboardLarge block-character charts of the CPU and RAM history.

Built to stay small

Light enough to leave running

  • Memory budgets: about 8 MB without plugins and about 12 MB with the seven default plugins. The core stays under 10 MB and the default setup under 14 MB. The status bar shows Telemetrix's own memory.

  • A settings file that cannot break: everything lives in a commented telemetrix.toml. A wrong value never breaks it.

  • Plugins that keep going: when a service is down, a card keeps its last values and marks them stale. No accounts or keys are needed.

  • Updates itself: telemetrix update gets the new version from GitHub Releases and checks the SHA-256 sums before it installs.

Screensaver

Use it as a screensaver

telemetrix screensaver install --idle-minutes 10

On Windows, this opens Telemetrix full screen in Windows Terminal after 10 idle minutes. Any key closes it. On Linux, use swayidle or xautolock: see the README.

Quick start

Four commands

telemetrix                       # the dashboard
telemetrix --exit-on-any-key     # screensaver mode
telemetrix snapshot              # print the numbers once
telemetrix screensaver install   # start it after idle time (Windows)

Keys: t theme, s settings, l log, ? all keys, q quit. Every change is saved at once.
