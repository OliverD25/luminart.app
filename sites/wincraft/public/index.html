The Command Palette (Win+Alt+P)

One Search Box for Everything—Plus a Live Inspector

Summon the palette right on the monitor where your cursor lives. Type a few letters to launch apps, switch windows across virtual desktops, calculate math as you type, or search every drive in milliseconds via Everything.

New: The Live Inspector & Intent Memory

  • Live Window & Action Inspector: A side panel follows your selection with a live window preview, process ID, RAM usage, virtual desktop location, and every available keyboard action. Select multiple windows (Ctrl+Space or Ctrl+A) to batch-move across monitors, minimize, or close them at once.
  • Learns Your Habits: WinCraft remembers what you typed before picking a result. Type the same shorthand again and your favorite match jumps straight to the top.

Seven Built-In Power Plugins

Seven Essential Tools. Zero Extra Processes.

Every feature runs inside a single unified host process—sharing one tray icon, one hotkey manager, and one clean settings window.

  • WindowDeck — Live Taskbar Previews & Visual Arranger (Win+Alt+A)

    See all windows of an app laid out by monitor in a live strip above your taskbar. Pick, close (Ctrl+W), rename (F2), or drag windows across monitors and virtual desktops. Optionally replace Windows 11's native taskbar hover preview (0.15s hover) or bind Win+1…9 to cycle and manage app windows at lightning speed.

  • QuickJump — Neovim's Harpoon for Your Windows (Win+Alt+Q)

    Pin up to 10 essential windows to digits 0–9 (Win+Alt+Shift+Q + digit) and jump back to any of them from anywhere (Win+Alt+Q + digit). Automatically switches virtual desktops, restores minimized windows, remembers pins across reboots, and even launches the app if it isn't running.

  • LayoutKeeper — Reboot-Proof Workspace Memory (Win+Alt+L)

    Remembers which virtual desktop and monitor every window belongs on, plus the exact order of thumbnails in your taskbar group. Reboot or unplug a display and restore your entire desk layout with a single shortcut.

  • ScreenDimmer — Hardware DDC/CI & Overlay Monitor Control (Win+Alt+F1/F2/F3)

    Cover idle monitors with a click-through black overlay that turns translucent under your cursor, or power displays down directly over DDC/CI (Win+Alt+Shift+F1/F2/F3) like a physical power button—without Windows scrambling your open windows onto your main screen.

  • WindowNamer — Persistent Custom Window Titles (Win+Alt+E)

    Turn three identical browser windows into "Mail", "Research", and "Bank". Custom names show up in the title bar, Alt+Tab, WindowDeck, and taskbar thumbnails—and stay put even when the app changes its page title or restarts.

  • ShortcutDetector — End Global Hotkey Conflicts (Win+Alt+S)

    See every global key combination already claimed on your PC and test shortcuts live before you assign them.

  • LanguageIndicator — Clean On-Screen Input HUD

    Switch from Ukrainian to English and get a sleek, click-through translucent HUD right in the center of your screen (UK → EN) that fades out smoothly without ever stealing window focus.

Designed for Customization & Control

Chord Shortcuts & Native Themes

  • Single-Press & 2-Step Chord Hotkeys: Bind any command in the palette (Ctrl+K) or Settings to a standard shortcut or a two-step chord like Win+Alt+K, S. Live status dots tell you immediately if a shortcut is active (✓) or claimed by another app (⚠).
  • 5 Native Themes with Live Hover Preview: Choose between Classic, Fluent (native Windows 11 glass that smartly turns solid on battery saver), Terminal, Paper, and High Contrast—each in Light, Dark, or System mode. Hover over any theme tile in Settings to preview it live across every open WinCraft window.

Architecture & Trust

Engineered to Respect Your Machine

  • 100% Portable & Admin-Free: One standalone wincraft.exe. Run it portably from any folder, or run wincraft.exe --install to set up a Start Menu shortcut and a user-level startup task—zero administrator privileges required.

  • Isolated, Crash-Proof JSON Configs: Settings live in %LOCALAPPDATA%\WinCraft with one JSON file per plugin. If a manual edit breaks a file, WinCraft safely falls back to defaults without overwriting your file or breaking your other plugins.

  • Self-Healing Updates: Optional daily update checks verify SHA256 checksums and automatically roll back to your previous executable if a new version fails to run cleanly for 30 seconds.

  • 100% Private (Zero Telemetry): No accounts, no analytics, no background data collection. Your layouts, bookmarks, and usage rankings never leave your PC.

  • 1-Trait Rust Plugin System: Want to add your own feature in an afternoon? Implement one Rust trait and describe your settings—WinCraft draws the UI, binds the hotkeys, and saves the config automatically.
