## Command palette

### The palette remembers your picks

Type a few letters and pick a result with Enter. WinCraft remembers it. Next time, the same letters, or the start of them, put that result first. Then Enter runs it at once.

In Settings, **Rank results by use** turns this off. **Clear usage history** makes WinCraft forget it.

### WinCraft commands above apps

When a WinCraft command matches, it now shows above apps with a similar name. For example, typing `upd` shows "Update WinCraft" above the apps whose names also match.
