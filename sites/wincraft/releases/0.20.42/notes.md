## QuickActions

QuickActions is a new plugin. It gives you Windows tools as palette commands. Type a few letters in the palette (Win+Alt+P) and press Enter.

### Commands

- Window: Toggle Always on Top
- Window: Center
- Window: Resize to 1280 × 720, 1920 × 1080, or 80 % of the Monitor
- Display: Toggle Keep Awake (with a tick in the tray menu)
- Theme: Toggle Dark Mode
- Desktop: Toggle Desktop Icons
- Taskbar: Toggle Auto-Hide
- File Explorer: Toggle Hidden Files and File Extensions

### Undo and hotkeys

Every change shows a WinCraft notice with Undo. If you run an action again, it switches the change back.

No action has a hotkey by default. Press Ctrl+K on one in the palette to give it one.
