## Arrange strip

### Windows from other monitors in the main column

The main taskbar lists windows from every monitor. The column of the main monitor now shows a faded stand-in for each window that lives on another monitor. The stand-in sits at the taskbar place of that window. So the numbers read 1, 2, 3, 4, 5 with no gaps.

A stand-in shows an arrow and the monitor name, a faded picture, the number and the title.

- Click a stand-in to select the real window card.
- Drop a card just before or after a stand-in to set its taskbar place next to that window.
- Arrow keys skip the stand-ins.

Stand-ins appear only when the main taskbar lists all windows. This is the Windows taskbar setting "Show my taskbar apps on".

### Fairer column widths

A column with few windows is now at most the share of the width that its monitor has.

## Settings

### New frame from the design

The side menu is wider (240 px). Each page has more space around it. The version number is larger. The settings window opens 1024 px wide.
