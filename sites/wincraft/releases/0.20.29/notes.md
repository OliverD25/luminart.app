## Download

### The exe says who made it and what it is

`wincraft.exe` now has a product name, a description, the MIT licence and an app manifest. Antivirus checks distrust programs that leave these empty.

## Project pages

### Privacy and code signing

The README has a new [Privacy](https://github.com/OliverD25/wincraft#privacy) section. It lists every case where WinCraft goes on the network. It also has a [Code signing policy](https://github.com/OliverD25/wincraft#code-signing-policy).

Free code signing by SignPath Foundation is applied for. Until then, releases are unsigned. `SHA256SUMS.txt` is the way to check a download.
