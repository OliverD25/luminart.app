## Settings

### Keyboard shortcuts page

Settings → Keyboard shortcuts lists every command, grouped by plugin. Click a row and press the keys to give it a shortcut.

- Search by name, plugin or keys. "Search by keys" shows what a key combination does.
- Use the filters All, Changed, No shortcut and Conflicts.
- Before saving, WinCraft explains problems in plain words. It names keys that Windows keeps for itself, and keys that another command or app already uses.
- Reset one shortcut, or reset all.

### Chord shortcuts

A shortcut can now be two key presses in a row, for example Win+Alt+K, then S. Press the second key within 3 seconds. A small WinCraft line shows while WinCraft waits.

## Command palette

### Shortcuts in the palette

Commands now show their shortcut. Press Ctrl+K on a command to open the Keyboard shortcuts page at that command.
