## Settings

### Plugins as compact rows

On the Plugins and Plugin Store pages, each plugin is now a compact row. It shows the icon, the name, a description of two lines, and one control at the end. Plugins shows the on/off switch. The Store shows Install or Installed.

## Fixes

### Recording special hotkeys

Recording a hotkey with Alt+Space, Alt+F4, F10 or Win+key no longer opens the window menu or the Start menu. All hotkey recorders share this fix.
