## Arrange strip

### Pictures keep the shape of the window

In the Arrange strip, every picture now has the same height, and its width follows the window. This applies to the hover strip, to Win+Alt+A, and to both views. Wide windows give wide cards, and narrow windows give narrow cards. The whole window is shown and is never cropped.

### Windows that want attention

When an app flashes a window for attention, for example for a new chat message, its card turns orange. This is like the orange highlight of the Windows taskbar. The card stays orange until you open that window.
