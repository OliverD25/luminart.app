## QuickActions

### Toggles show their state

QuickActions toggles now show their state in the palette. Each row has an icon tile, a line that says the state in words (for example "Dark for apps and Windows" or "Microphone is on"), and a switch.

Press Enter to flip a toggle. The palette stays open and the row updates. The WinCraft notice with Undo still appears. The state is read fresh every time the palette opens.

### Renamed command

"Desktop: Toggle Desktop Icons" is now "Desktop: Show Desktop Icons", so on means the icons are visible. Searching for the old name still finds it.
