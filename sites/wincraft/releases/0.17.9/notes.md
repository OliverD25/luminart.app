## Command palette

### Update from the palette

Press Win+Alt+P and type `upd`. **Check for updates** checks GitHub now. **Update to …** appears when a newer version exists. It installs that version, the same as Update now in About.

### `!` lists the WinCraft commands

Type `!` alone to see every WinCraft command. This includes settings pages, plugin actions and plugin on/off switches. Type `!` and a word to search only these commands.
