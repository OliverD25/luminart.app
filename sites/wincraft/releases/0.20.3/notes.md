## Settings

### Plugins and Plugin Store as a tile grid

Each plugin is now a tile. It shows the icon, the version, a short description, the category, and a switch or a button. Search with Ctrl+F and filter with the category chips. In the store, you can sort by name or by category.

## Arrange strip

### Change a window's number without moving it

Use one of these ways:

- Right-click a card and choose Taskbar place.
- Press Alt+←/→ on a selected card.
- Ctrl+drag a card onto another card.

The window stays on its monitor. Only its place in the Win+number order changes.

### The hover strip follows each taskbar

On the taskbar of a second monitor, the hover strip shows only the windows on that monitor. Windows does the same.

### Better column widths in the By monitor view

Columns take only the room their windows need. The busiest monitor gets the rest. An empty monitor folds into a thin rail. The rail widens while you drag a window.

## Log

The log now names which window flashed for attention.
