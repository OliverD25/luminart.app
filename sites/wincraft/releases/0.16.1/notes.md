## Command palette

### A calmer match highlight

Before, a search such as `pswds` underlined five letters spread across a long title. Now the palette shows only the first unbroken run of three or more matching letters, in the accent colour and with no underline. A query of one or two letters still highlights when the whole query appears unbroken, so `no` marks the start of Notion.
